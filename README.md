Projeto: Análise Exploratória, Modelagem Preditiva e Clusterização do Crédito Rural Brasileiro Utilizando Apache Spark

Este projeto aplica técnicas de Big Data utilizando Python + PySpark para analisar dados públicos do Banco Central (SICOR) sobre crédito rural no Brasil.
O trabalho segue o ciclo KDD (Knowledge Discovery in Databases), incluindo ingestão, pré-processamento, análise exploratória, modelagem preditiva e clusterização.

Tecnologias:
Python
PySpark (DataFrames, SQL, MLlib)
Requests, Matplotlib, Seaborn, Scikit-learn

Execução: 
Execute o notebook em Google Colab, Databricks CE ou localmente com Spark.
Rode todas as células em ordem — o notebook é reprodutível do início ao fim.


Resultados:
  Ranking de estados/regiões com maior crédito rural.
  Evolução anual e mensal.
  Programas e fontes de recurso mais relevantes.
  Comparação de modelos (Árvore de Decisão × Random Forest).
  Clusterização dos estados em perfis distintos.
